Sokrates is an intellectual matchmaking web application designed for 1-on-1 and group philosophical conversations, enhanced by AI for semantic matching, real-time fallback dialogs, automated discussion starters, post-chat summaries (digests), and interactive argument map visualization.

## Requirements

### R1. Authentication & Profiles
User signup and login (via Supabase Auth) with a multi-select interest picker to construct the user's intellectual profile. The profile interest vector should be dynamically updated and saved in the database using text embeddings.

### R2. Group Discussion Rooms & Feed
A home feed displaying active group rooms and browseable system topics. Users can create group rooms (with customizable topic, description, category, and participant cap). Real-time group chat is supported via WebSockets (Socket.io) with typing indicators and creator-moderated join requests.

### R3. 1-on-1 Matchmaking & Watchlist
A queue-based matchmaking system where users entering the queue for a topic are semantically matched with other users using cosine similarity on their profile interest vectors. Users can watch system topics to receive real-time notifications when others enter the queue.

### R4. Real-time AI Fallback
If a user is in the matchmaking queue for 30 seconds without a human match, they are automatically placed into a room with an AI conversation partner that streams responses (using a fast, conversational Llama model) in real time over WebSockets.

### R5. Post-Chat AI Digest & Argument Mapper
When a 1-on-1 conversation ends, the system uses an LLM to generate a structured 3-sentence summary (digest) highlighting each participant's stance and the best open questions, alongside extracting the logical graph of the conversation (claims, evidence, rebuttals, concessions, agreements) as an interactive argument map.

### R6. Public Debates & Admin Dashboard
An option for participants to publish their 1-on-1 conversation transcripts to a public feed. An admin dashboard provides site statistics, user suspension tools, force-end room controls, and system topic CRUD operations.
